# نظام إدارة شركة الطيران (Django Admin)

نظام لإدارة شركة طيران مبني بالكامل على لوحة تحكم Django. يدعم العربية والإنجليزية.

## التشغيل

افتح `run_server.bat` بنقرة مزدوجة. في أول تشغيل ينشئ قاعدة البيانات والبيانات التجريبية، وبعدها يفتح
http://127.0.0.1:8095/admin/

أو يدويًا (من داخل مجلد `airline_admin`):

```
..\venv\Scripts\python.exe manage.py migrate
..\venv\Scripts\python.exe manage.py seed_data
..\venv\Scripts\python.exe manage.py runserver 8095
```

## الحسابات التجريبية (تنشئها `seed_data`)

| المستخدم | كلمة المرور | الدور |
|---|---|---|
| admin | admin123 | مدير النظام: كل الصلاحيات والمستخدمين |
| agent | agent123 | موظف حجز: الحجز والدفع والإلغاء وتغيير المقعد |
| airport | airport123 | موظف مطار: تسجيل الوصول والأمتعة والبوابات وحالة الرحلة |
| ops | ops123 | مدير عمليات: الرحلات والطائرات والصيانة والطاقم والتقارير |

غيّر كلمات المرور قبل أي استخدام حقيقي.

## ماذا يوجد

- **الحجز** (حجز جديد): بحث، ثم اختيار رحلة أو أكثر (ذهاب، ذهاب وعودة، أو متعدد الوجهات)، ثم بيانات المسافرين
  والمقاعد، ثم الدفع، ثم إصدار PNR والتذاكر وإرسال بريد التأكيد.
- **منع الحجز المزدوج**: المقعد يُحجز مؤقتًا 10 دقائق ويتحرر إذا لم يتم الدفع. قاعدة البيانات نفسها تمنع بيع
  نفس المقعد مرتين، مع Transactions وقفل الرحلة أثناء الحجز.
- **التسعير الديناميكي**: السعر = الأساسي × الدرجة (1 / 2.5 / 4) × قرب الموعد (حتى +50%) × الإشغال (حتى +50%).
- **الإلغاء والاسترداد**: 100% قبل 72 ساعة، 50% قبل 24 ساعة، وبعدها لا يوجد استرداد. إلغاء الرحلة من الشركة يسترد
  المبلغ كاملًا لكل المسافرين.
- **تسجيل الوصول**: يفتح قبل 24 ساعة ويغلق قبل 45 دقيقة من الإقلاع. بطاقة صعود فيها QR، والأمتعة بأرقام بطاقات
  ومتابعة للوزن المسموح.
- **الطائرات**: مخطط المقاعد يُنشأ تلقائيًا من عدد الصفوف لكل درجة، مع جدول للصيانة.
- **الطاقم**: لا يمكن تكليف فرد بطاقم رحلتين بنفس الوقت أو تجاوز ساعات الطيران الشهرية المسموحة.
- **الإشعارات**: بريد عند التأكيد والإلغاء وتغيير الحالة والبوابة والموعد. كل رسالة تُسجل في جدول الإشعارات.
- **برنامج الولاء**: ميل لكل وحدة نقدية مدفوعة، مع فئات أزرق وفضي وذهبي وبلاتيني.
- **التقارير ولوحة التحكم**: الإشغال، الإيرادات الشهرية، أكثر الوجهات طلبًا، ونسبة الإلغاء.

## الإعدادات

في `config/settings.py`: اسم الشركة، العملة، مدة الحجز المؤقت، نافذة تسجيل الوصول، والوزن المسموح للأمتعة.

- **البريد**: يُطبع في الطرفية افتراضيًا. اضبط `DJANGO_EMAIL_BACKEND=django.core.mail.backends.smtp.EmailBackend`
  مع `EMAIL_HOST` وما يتبعها للإرسال الحقيقي.
- **SMS**: الرسائل تُسجل فقط. اربط بوابة الإرسال في `send_sms` داخل `airline/notifications.py`.
- **PostgreSQL**: اضبط `POSTGRES_DB` و`POSTGRES_USER` و`POSTGRES_PASSWORD` و`POSTGRES_HOST`.
- **الإنتاج**: `DJANGO_DEBUG=0` و`DJANGO_SECRET_KEY` و`DJANGO_ALLOWED_HOSTS`. عندها يتفعل HTTPS والكوكيز الآمنة وHSTS.
- **الدفع**: في وضع الاختبار، يتم تسجيل الدفعة بدون خصم حقيقي. لربط Stripe أو PayPal استبدل `pay_booking` في `airline/services.py`.
